# Changelog

All notable changes to NTIV are documented here. NTIV follows Semantic Versioning.

## [0.5.0] - 2026-09-29

### Added

- Vim-style keyboard navigation, tabs, split browsing, favorites, and command palette.
- File-name and content search with live previews.
- Visual multi-selection and background copy, move, rename, create, and recycle jobs.
- Safe undo support for reversible file operations.
- ZIP archives that open as read-only folders.
- Git status, text comparison, application launcher, configurable plugins, and six themes.
- Optional mouse learning mode with a contextual menu.
- Hebrew and mixed right-to-left filename display support.
- Windows Terminal profile, live clock, and polished status line.

### Distribution

- Added portable Windows x64 packaging and WinGet community manifests.
