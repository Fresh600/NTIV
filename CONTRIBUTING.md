# Contributing to NTIV

Thank you for helping improve NTIV.

1. Open an issue before beginning a large feature or behavior change.
2. Create a focused branch and keep unrelated changes separate.
3. Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and
   `cargo test` before submitting a pull request.
4. Add or update tests for behavior changes.
5. Keep keyboard workflows accessible and preserve terminal restoration on every
   exit and error path.

By contributing, you agree that your contribution is licensed under the MIT License.
