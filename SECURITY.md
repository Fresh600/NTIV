# Security policy

## Supported versions

Security fixes are provided for the latest published NTIV release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature in the NTIV repository instead. Include
the affected version, reproduction steps, expected impact, and any suggested fix.

NTIV does not require Administrator privileges. File-changing operations run with
the permissions of the current Windows user.
